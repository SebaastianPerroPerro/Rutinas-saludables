# Grupo 1 - Creación de hábitos

## Trabajar aquí

Esta carpeta es exclusiva para la funcionalidad de creación de hábitos.

## Responsabilidad

- Crear un hábito con nombre, descripción opcional, meta semanal y color.
- Validar los datos antes de guardarlos.
- Guardar el hábito usando el contrato común del proyecto.

## Entregables

- Implementación de creación de hábitos.
- Validaciones de campos obligatorios.
- Pruebas en `tests/grupo1`.
- Una breve explicación del uso en este archivo.

## Demostración

Crear un hábito válido, rechazar datos incompletos y comprobar que el hábito permanece después de recargar la aplicación.
