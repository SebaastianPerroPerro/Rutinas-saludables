# Grupo 4 - Rachas de hábitos

## Trabajar aquí

Esta carpeta es exclusiva para calcular rachas a partir de los cumplimientos diarios.

## Responsabilidad

- Calcular la racha actual de cada hábito.
- Calcular la mejor racha histórica.
- Detectar interrupciones entre fechas consecutivas.
- Manejar correctamente hábitos sin cumplimientos.

## Entregables

- Implementación de los cálculos de rachas.
- Pruebas con días consecutivos y días faltantes en `tests/grupo4`.
- Una breve explicación del uso en este archivo.

## Demostración

Mostrar una racha de varios días, interrumpirla y comprobar que la mejor racha anterior se conserva.
