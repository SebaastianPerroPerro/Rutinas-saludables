# Grupo 3 - Registro de cumplimiento diario

## Trabajar aquí

Esta carpeta es exclusiva para registrar el cumplimiento de un hábito en la fecha actual.

## Responsabilidad

- Marcar un hábito como cumplido hoy.
- Guardar la fecha exacta del cumplimiento.
- Impedir registros duplicados para el mismo hábito y fecha.
- Mostrar si el hábito de hoy ya fue completado.

## Entregables

- Implementación del registro diario.
- Integración con el almacenamiento definido por el equipo.
- Pruebas en `tests/grupo3`.
- Una breve explicación del uso en este archivo.

## Demostración

Marcar un hábito, recargar la aplicación y comprobar que el cumplimiento sigue guardado y no se duplica.

Nota: el archivo `HabitoTest.java` ya existía en esta carpeta y se conserva. Coordinen su uso con la tecnología principal del proyecto antes de añadir más archivos Java.
