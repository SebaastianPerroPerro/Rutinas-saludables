# Pruebas del Grupo 2

Coloca aquí las pruebas de listado y gestión de hábitos.

`gestionHabitos.test.js` prueba el listado, la edición, la desactivación/reactivación, la eliminación y que los cambios se conservan al volver a leer el almacenamiento. Usa un `localStorage` en memoria, así que no necesita navegador:

```bash
npx vitest run tests/grupo2
```
